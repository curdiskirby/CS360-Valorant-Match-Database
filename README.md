# CS360 Valorant Match Database
A mockup database to practice SQL and database management based on Valorant and its match systems. The Database is meant to provide the persistent storage for the competitive match-tracking and stats system for the game. Each player plays a specific agent with special abilities and is able to customize their loadout of weapons and receive detailed performance stats after the match is concluded.
